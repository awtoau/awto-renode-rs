# State of the transpiler, 2026-08-02

What is built, what is proven, what is assumed, and what is open. Every number
here is measured by a committed script and reproducible; where something is
unverified it says so.

`STATUS.md` is the generated scorecard. This is the narrative one, written
because the numbers alone do not say which are load-bearing.

---

## What the converter is

A C#-to-Rust transpiler driven by a corpus database, not a Renode port. Renode
is the corpus that tells us which constructs matter.

    frontend/RenodeIngest/     Roslyn walk -> SQLite corpus
    rulesdb/rules/*.json       the knowledge, as DATA
    scripts/emitter/lang/      generic C#, corpus-agnostic
    scripts/emitter/plugins/   corpus idioms, consulted FIRST
    src/csharp-rt/             runtime support: types C# has and Rust lacks

`check_layering.py` fails the commit if the generic layer names a corpus
construct. That boundary was convention until it was enforced, and it caught
four violations the day it landed.

## What is proven

**Generated UART replays 33,164 recorded register accesses with zero
divergences.** The hand-written `uart.rs` passes the same trace, so on the
largest oracle this project has, converter output is indistinguishable from the
file a person wrote.

Eight traces now replay against generated code:

| trace | accesses | divergences | accuracy |
|---|---|---|---|
| usart1 | 33,164 | 0 | **100.0%** |
| exti | 25 | 0 | **100.0%** |
| adc1 | 16,800 | 1,192 | 89.6% |
| syscfg | 9 | 2 | 66.7% |
| gpioPortA | 62 | 14 | 17.6% |
| can1 | 228 | 99 | 13.9% |
| dma1 | 183 | 88 | 9.3% |
| dma2 | 12,356 | 6,164 | 0.2% |

The low rows are low for **named reasons**, not general incompleteness — DMA
needs sub-peripheral composition (#55), GPIO needs peer-call type resolution
(#54). That is a better position to resume from than a gap count.

**The rules generalise.** Built against two peripherals, the converter emits
**470 of 569 modules across all of Renode** that compile — 82.6%, 152,925
lines. Gap distributions between the F427 cut and the whole tree agree to
**2.0 percentage points**.

**Rules mined from a Python-to-Rust project transferred unchanged**, because
the Rust-target half of a translation rule is language-pair independent. The
discriminator: *"Python X becomes Rust Y"* is source-side and worthless;
*"Rust rejects Z, emit W instead"* transfers.

## What is assumed, not proven

**Compiling is not working.** c2rust emits output >99.99% of the time and only
72.64% of it runs. 470 modules compile; 8 have ever been executed.

**Trace replay proves indistinguishability on that trace, nothing more.** The
invented `.with_reserved(9, 23)` survived a 33,000-access trace and 81%
mutation testing, because behaviourally inert wrong code is invisible to replay.

**Threading is uncertified and cannot currently be certified** (#52). Trace
replay is single-threaded by construction, so a threading difference cannot
appear in it. 842 `lock` sites are preserved as `Mutex` with the timing
explicitly not claimed.

**No dynamic evidence exists.** The ownership classification
(`docs/status/ownership.tsv`) is static: declared types and access counts. A
field never null in practice still looks nullable.

## The three checks, and what each is worth

| check | proves | blind to |
|---|---|---|
| `check_generated` | 7 modules byte-reproducible from rules alone | whether the rules are right |
| `compile_check` (ratchet) | well-formed | whether it behaves |
| trace replay | behaviour matches recorded C# | anything the trace does not exercise |

Each found bugs the others could not. The compile check found `x as i32 << 8`
(400 errors, one construct). Trace replay found `out arr[i]` binding to nothing,
which compiled, was byte-reproducible, and produced no gap.

## The failure mode that dominated

**Six paths produced no output and reported no reason.** Each was
indistinguishable from a rule that correctly declined, so review could not
catch them. Two were reported as landed before anyone noticed; one survived
two commits. Four came from editing by string match against anchors moved by a
refactor.

The remedy was tooling, not discipline: `core.must_explain` raises when a
guarded path emits nothing without recording why; the wiring guard raises when
a rule named in data has no handler; the ratchets catch regressions no test was
watching. Each found something the day it landed.

**Four bugs compiled cleanly and were wrong**: a self-call recursing forever, a
`/* GAP */` comment left in a loop increment, an unmapped return type falling
back to `-> ()`, and `16.0` emitted as `16`. None failed to compile. "It
builds" is not evidence.

## The measurement that reframes the object graph

552 instance fields: 243 values, 94 arena handles, 73 callbacks, **47 shared
and 19 back-references**. 52 object-reference edges, **7 cycles**, all named in
`docs/status/ownership.mmd`.

That is the argument against a tracing GC — seven cycles is seven `Weak`
edges, not a collector — and it was invisible until it was measured.
