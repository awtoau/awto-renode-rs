## The two things blocking everything

**1. Nothing has ever executed.** The converter emits effectively none of the
infrastructure — `SystemBus` gives an *empty* `define_registers` from 200
members, `MappedMemory` 4 trivial getters from 74. 594 compiling modules with no
bus is 594 files.

Target: `tests/unit-tests/stm32f4-erase.robot :: Should Perform Mass Erase` —
3 server keywords, 5 monitor verbs, no CPU, no ELF. Renode's 265 Robot tests are
language-neutral and need no translation.

**2. The oracle cannot see behaviour.** Add a clock and an init-write seed to
the replay harness, or ADC, DMA and every timer peripheral stay unverifiable
however well they are translated.

## Rules found wrong this week

Not incomplete — wrong:

- `<<` / `>>`, **255 sites**: C# masks the shift count (ECMA-334 §12.11); `1 << 32` is `1` in C#, a panic in Rust
- `Dictionary.Add`, **86 sites**: C# throws on a duplicate key; `insert` overwrites
- `OrderBy` → `{recv}`: a sort that does not sort
- `First` → `.unwrap()`: C# throws `InvalidOperationException`
- LINQ keyed by name only, so every overload took the first overload's template
- `String.Append` / `ToString` keyed on the *Rust* type: could never match, counted as coverage
- `Nullable.Value` / `HasValue` missing, 26 sites, emitting `x.value()` on `Option<T>`
